How to add it to Outlook
  1. Download the .ics file using the button above.
  2. In Outlook on the web, open Calendar → Add calendar → Upload from file.
  3. Choose my-ai-world-agenda.ics, select a destination calendar, and import.

Your calendar shows events in its selected timezone; the agenda above uses Las Vegas time. Import once into a separate conference calendar to keep the plan easy to manage.
